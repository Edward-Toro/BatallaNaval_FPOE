# Batalla Naval 🚢

Miniproyecto #4 de FPOE (750014C) - Universidad del Valle, 2026-1.

Juego de Batalla Naval en JavaFX, 1 jugador humano vs máquina, con dos
tableros de 10x10 (posición y ataque).

## Requisitos

- JDK 25
- Maven (o usar el wrapper: `./mvnw` / `.\mvnw.cmd`)

## Cómo correrlo

```bash
mvn clean compile
mvn javafx:run
```
